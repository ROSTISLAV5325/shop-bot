# ☕ Shop Bot — Telegram-магазин для кав'ярні

Telegram-бот, у якому клієнти переглядають меню з фото, збирають кошик і оформлюють замовлення, а власник керує товарами і замовленнями прямо в Telegram — без програміста.

## Для клієнта

- 🛍 **Каталог** з категоріями, фото, описом і ціною
- 🛒 **Кошик:** додати, змінити кількість (➖ ➕), очистити — сума рахується автоматично
- ✅ **Оформлення:** ім'я → номер телефону (кнопкою) → доставка або самовивіз → адреса → підтвердження
- 📦 **«Мої замовлення»** зі статусом і сповіщеннями про його зміну

## Для власника (`/admin`)

- ➕ **Додавання товарів** з фото, описом і ціною
- ✏️ **Редагування:** змінити ціну чи фото, сховати товар з каталогу або повернути його
- 📁 **Нові категорії** в один крок
- 🔔 **Сповіщення про нові замовлення** з кнопками «Прийняти / Відхилити / Виконано» — клієнт одразу отримує новий статус
- 📋 **Список необроблених замовлень**

## Технічні деталі

- Python 3.10+, [aiogram 3](https://docs.aiogram.dev/), SQLite
- FSM (машина станів) для покрокових сценаріїв
- Ціни в замовленні зберігаються на момент покупки — зміна ціни не змінює старі замовлення
- Створення замовлення — в одній транзакції (замовлення, товари, очищення кошика)
- «М'яке видалення» товарів і автоматична міграція структури бази
- Захист адмінки фільтром за Telegram ID

## Запуск

1. `pip install aiogram`
2. Створити бота в [@BotFather](https://t.me/BotFather)
3. Задати змінні середовища:
   - `BOT_TOKEN` — токен бота
   - `ADMIN_ID` — Telegram ID власника магазину
4. `python bot.py`

При першому запуску база заповнюється демо-товарами.

## Структура

```
bot.py — логіка бота: каталог, кошик, оформлення, адмінка
db.py  — робота з базою даних SQLite
```
